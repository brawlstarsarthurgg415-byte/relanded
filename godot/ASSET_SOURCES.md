# Relanded — third-party asset register

The Android build workflow downloads the following original GLB assets into `godot/models/` before Godot imports the project. The models are included in the APK; the player does not need an internet connection to load the environment.

| In-game file | Source | Licence |
|---|---|---|
| island_lagoon.glb | 3DAssets.dev — Lagoon beach / Tropical Island and Palm Trees | CC0 1.0 |
| palm_tall.glb | 3DAssets.dev — Tall coconut palm | CC0 1.0 |
| palm_leaning.glb | 3DAssets.dev — Leaning shore coconut palm | CC0 1.0 |
| shells.glb | 3DAssets.dev — Beach shell scatter | CC0 1.0 |
| driftwood.glb | 3DAssets.dev — Driftwood log | CC0 1.0 |
| spring.glb | 3DAssets.dev — Freshwater spring pool | CC0 1.0 |
| lean_to.glb | 3DAssets.dev — Palm-frond lean-to | CC0 1.0 |
| hiker.glb | tevy — Hiker (LOD2) | CC0 1.0 |

Sources:
- https://3dassets.dev/packs/tropical-island-ecology
- https://3dassets.dev/api/v1/packs/tropical-island-ecology
- https://tevy.dev/models/hiker

These are existing third-party 3D models, not meshes generated by the Relanded project. Their original licences permit use without attribution. This register is retained for provenance and reproducible builds.
